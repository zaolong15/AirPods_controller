# PodsBridge v2

让安卓手机用上 AirPods（重点 AirPods Pro 2）通常只有苹果设备才有的控制功能。
协议字节来自 LibrePods 项目公开的 AAP 逆向文档；本项目为独立实现，与 LibrePods / Apple 无隶属关系。

## 已实现
- 噪声控制四档（关闭/降噪/通透/自适应）、自适应强度 0–100、对话感知开关、重命名
- 电量（左/右/盒）、佩戴检测 → 自动暂停/恢复；说话时自动降低媒体音量
- 常驻通知快捷切换、快速设置磁贴（点击循环降噪模式）
- 待命模式：AirPods 连上手机后自动接管，开机自启，设置与 EQ 参数持久化
- 连不上 AACP 时：BLE 广播读取电量（实验）+ 一键复制诊断报告
- 点头接听 / 摇头拒接（需先各录入一次动作，实验）
- 均衡器（按设备频段数自适应）、低音增强、虚拟环绕（对广播音频会话的播放器生效）

## 未实现（原因见对话说明）
听力辅助/听力测试、通透模式细调（放大/音调/对话增强）、长按柄配置、定位(Find My)、
个性化空间音频与系统级头部追踪声场、多设备无缝切换、伪装 Apple 设备 ID。

## 云端打包
1. GitHub 新建仓库，把本目录全部文件（含 .github/workflows）上传到 main 分支
2. Actions → Build APK → 运行完成后在页面底部 Artifacts 下载 PodsBridge-apk
3. 解压得到 app-debug.apk，安装即可

## 首次使用
1. 系统蓝牙里先配对 AirPods；打开 App 授权「附近的设备」与通知
2. 控制页选择 AirPods → 连接。失败时去「诊断」页点「复制完整诊断报告」
3. 连接成功一次后可开启「待命模式」
4. 小米：电池 → 本 App 设为「无限制」，并开启自启动
